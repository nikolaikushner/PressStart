This repository is the **corresponding source** for official App Store builds of Press Start: the SwiftUI app under `PressStart/`, build scripts, skins, and documentation that describe how to obtain and link DeltaCore and the system cores.

## How to rebuild

Follow [README.md](README.md): install XcodeGen, run `PressStart/scripts/bootstrap-cores.sh`, `xcodegen generate`, link the Vendor cores, then archive with your Apple Developer team.
